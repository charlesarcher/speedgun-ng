speedgun-ng/hunt.hpp file

The hunter-mode surface of specs/029: the catalog selection, the plan, the collected samples, the ranked result and the run record.

Contents

  • Reference
    • Namespaces

Feature 029-hunter-core. Namespace sg::hunt. The surface measures nothing: it declares no clock, no counter read, no /proc, no sysfs and no CPUID, so every time and count figure a record holds comes from an argument, the catalog or the run that filled it (I-7, FR-003). No internal harness type reaches any signature (D-15).
