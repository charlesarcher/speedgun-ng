sg::GraphEdgeRecord struct
#include <speedgun-ng/benchmark.hpp>

specs/037-execution-graphs: one dependency pair as the record carries it (FR-014, FR-023).

Contents

  • Reference
    • Public variables

The two fields are the keys of one edges entry, in the order the schema's x-order states: from, to.

from and to each name a node of the graph the run read, and the pair names no self-edge: the reader refuses a dependency that names no node and a node that names itself before any record is built (FR-010 rules 7 and 8). The writer emits the two fields as the entry's two keys, and loadReport reads them back equal (FR-023). The edge array carries one entry per dependency in the graph file's order, the order the record and the console print (FR-014, FR-023).

The struct is data: it has no call to guard.
