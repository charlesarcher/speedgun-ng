sg::ResultRow struct
#include <speedgun-ng/benchmark.hpp>

One repetition row or one aggregate row (E-06).

Contents

  • Reference
    • Public variables

A repetition row carries the values of that repetition's measured run. An aggregate row carries timeStats and one metricStats entry per metric, and appears only when the repetition count exceeds one (FR-027, FR-035).
