sg::State class
#include <speedgun-ng/benchmark.hpp>

The object the harness hands the benchmark function (E-03).

Contents

  • Reference
    • Public types
    • Public static functions
    • Public functions

The function runs its setup, the timed loop as for (auto _ : state), and its teardown; setup and teardown sit outside the loop, in the untimed region (FR-004, FR-005). The sampling window opens in begin() and closes when the loop runs out, so the window covers the loop and not the setup or the teardown (FR-017). The loop cursor counts down from the iteration count of the current run, so it cannot pass that count by construction, and the loop reads no interrupt flag: the runner reads that flag after a run completes (R-06).

Cursor sg::State::begin() noexcept

The cursor at the first iteration of the timed loop.

The skip flag is read here, once for the loop. A skip requested before the loop leaves the loop with no pass at all and takes no sample. Otherwise this is where the run's sampling window opens, before the first pass of the loop and after the setup the function already ran (FR-005, FR-017).

Precondition

this state belongs to a run: a callback state opens no sampling window, so opening one here is a precondition violation (R-05)

Postcondition

the returned cursor names iteration zero of this run with the entry sample taken, or an empty cursor when the function already requested a skip

void sg::State::skipWithError(std::string_view reason) noexcept

Skip the benchmark with an error reason (FR-031).

A skip inside the loop closes the sampling window at once, so the measured window stops where the function stops, the way the upstream timer stops its clock (FR-017).

Precondition

this state belongs to a run: a skip in a callback state is a precondition violation (R-05)

Postcondition

the reason is recorded, the function leaves the timed loop with break or return, and no statistics print for this benchmark

void sg::State::setIterationTime(std::int64_t nanoseconds)

Add one iteration time to the manual accumulator (FR-007).

A manual benchmark supplies its own time: this call takes one nanosecond count per iteration and the harness records the sum of the accepted values by summation alone, with no clock behind it. The real column of the run shows that sum divided by the iteration count (FR-006, FR-007, D-05). The call stands in the benchmark body, inside the timed loop or outside it, and the run state owns the accumulator.

Precondition

this state belongs to a run: a callback state owns no run to accumulate for, so accepting a value there is a precondition violation (R-05, D-15)

the count is at least zero: a duration has no negative nanoseconds, and a negative value is accepted nowhere without naming its caller (FR-007)

Postcondition

the manual accumulator carries the sum of every accepted value, this one included (FR-007)

void sg::State::pauseTiming()

Stop the timed window from this point (FR-009).

The call stands in the benchmark body. It takes one sampling action, the same action the endpoint pair takes, and opens one pause interval that resumeTiming closes (FR-009). The runner folds every closed interval and subtracts it from each column of the row (FR-010). The allowance guard runs before the sample, so the breach is named while the recorder still holds its points (FR-014).

Precondition

this state belongs to a run, its sampling window stands open and unclosed, no pause stands open on it, and its pause count stands below kMaxPausePerRun (FR-011, FR-014, D-15)

Postcondition

one further sample stands in the run's span and one pause is open (FR-009)

void sg::State::resumeTiming()

Restart the timed window and record the interval it paused (FR-009).

The call takes the sample that closes the open pause, records the pair of sample ordinals of that interval inside the run's span, and counts one interval against the run's allowance (E-03, FR-018).

Precondition

this state belongs to a run and one pause stands open on it (FR-011, D-15)

Postcondition

one further sample stands in the run's span, the ordinal pair of the closed interval stands in the run's pause list, and no pause is open (FR-009, E-03)
