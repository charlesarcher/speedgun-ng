std::expected<void, Error> sg::counters::System::registerProvider(std::unique_ptr<ProviderIface> provider)

Registers a provider and merges its objects (FR-009).

Registration after the system opened is a recoverable error. A duplicate canonical path under one parent, a duplicate counter name within one object, or a platform alias already resolving to another object is a recoverable error naming the clash, and the whole provider is refused with the tree left unchanged (FR-008, FR-002). A provider unit token outside the closed mapping is a recoverable error naming the unit (FR-017).

std::expected<Counter<Dim<0, 1>>, Error> sg::counters::System::tsc() const

Resolves the time-stamp counter as a shorter spelling of resolving the tsc entry under the machine object (specs/008-timestamp-counter FR-004).

The returned counter is the same type the uniform lookup returns and names the same canonical entry, so the two are interchangeable at the call site and the result composes with every other counter. The call resolves an entry and reads nothing: no hardware read, no plan, and no recorder. It does not open the registration boundary, so a program may call it and then register a provider.

No clock provider registered is a recoverable error naming the absent provider, and a build whose host does not execute the instruction is a recoverable error naming the absent counter. Neither returns a counter.
