sg::ContextDisclosure struct
#include <speedgun-ng/benchmark.hpp>

The policy disclosure of one context of a threaded run (E-07, FR-025).

Contents

  • Reference
    • Public variables

The runner fills one record per context of a threaded instance from that context's fixed policy when the instance joins its contexts, and the report prints the pair after the rows of the result (FR-025). A record is the policy the context was created with: a policy is fixed at creation and readable for the context's life (FR-007), so the pair names what that context ran under. placement holds the printable placement, NO_PIN or one cpu index, the description the installed placement function returned for that context's thread (FR-005, FR-025).

Variable documentation

std::string sg::ContextDisclosure::group

The context group this context belongs to, empty where the run carries no partition (FR-005, FR-029).

The run's partition names one text per group: <unit>-<ordinal> for the unit a preset plan reads, the text a layout entry states, or g beside the entry index where an entry named none (D-4). The console prints the name as the last segment of its context line and the report writes it as the record's group key, so both read this one text (FR-028, FR-029).

Precondition

none

Postcondition

a name with text stands unique within the run's partition and names the group holding this context (A-1, A-2 of the partition contract); an empty name states the ungrouped shape, the record a report document that carries no group key loads as (FR-004, FR-031, FR-033)

Invariant

the console segment and the report key print this one text, and the runner fills it from the instance's partition as it fills the disclosure record, so both channels answer one name for one context (FR-028, FR-029, FR-033)
