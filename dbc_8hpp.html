#define SG_CT_REJECT(pred)

Compile-time contract layer (FR-022 / FR-023 / FR-024).

Constraints evaluable at compile time (type properties, template-parameter ranges, size relations) must be expressed with static_assert, a concept, or a constexpr validator — not a runtime SG_* check. Those forms are active in every configuration at zero runtime cost. Constexpr-only interfaces are constrained through this layer and are exempt from runtime enforcement. A runtime SG_* check whose predicate is a compile-time-true constant is a compile error.
