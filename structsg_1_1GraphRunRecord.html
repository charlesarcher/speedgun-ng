sg::GraphRunRecord struct
#include <speedgun-ng/benchmark.hpp>

specs/037-execution-graphs: one threaded run's graph facts as the record carries them (FR-023, D-5 of research.md).

Contents

  • Reference
    • Public variables

The five fields are the keys of one runs entry, in the order the schema's x-order states: benchmark, nodes, edges, held, stopped.

benchmark names the benchmark of the run the entry describes, nodes carries one entry per node of the graph in ascending slot order, edges one entry per dependency in the file's order, held one entry per held node in ascending slot order, and stopped the stopped node names in ascending slot order (FR-019, FR-020, FR-023). The writer emits the five fields as the entry's five keys, and loadReport reads them back equal (FR-023). The entry names one threaded run and carries no timing figure: the graph times nothing (FR-024).

The struct is data: it has no call to guard. The check over the node order stands at the writer's edge, where writeReport requires the ascending slot order of every run's nodes (FR-023).
