sg::hunt::RunHunt struct
#include <speedgun-ng/hunt.hpp>

The run-level hunt record on ReportData::hunt (E-08, PD-10).

Contents

  • Reference
    • Public variables

The harness run path assembles it from the plan and the stages that ran; it stands empty for a run that carried no hunt (I-8). The cut reason of a plan that dropped a stage stands on the record, so the plan line prints what the planner decided. A printer adds no word of its own.
