sg::counters::FanoutPlan class
#include <speedgun-ng/counters_measurement.hpp>

A fan-out plan (US3 scenario 5, SC-007): the exemplar expression instantiated per selected object; every instantiated leaf is read inside each shared sampling action (FR-047). Move-only; the plan owns the layout and the recorder arenas.
