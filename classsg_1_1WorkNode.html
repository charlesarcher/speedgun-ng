template<WorkItem Item>
sg::WorkNode class

The caller-owned carrier of one typed work item (E-03, FR-009).

Contents

  • Reference
    • Base classes
    • Constructors, destructors, conversion operators
    • Public functions

Construction stamps the one erased run path from Item, so the loop runs no run-time type test on it (FR-009, D-02). The node lives in caller storage and stays alive until its state settles; destroying a live node is a contract violation under the enforce semantic, and a reader that observes DONE or STOPPED may destroy or reuse the node (FR-012, FR-049). The node names no context, so it carries no wait helper: the caller uses ExecutionContext::drain() or state() (FR-004).

template<WorkItem Item>
sg::WorkNode<Item>::WorkNode(Item item) explicit

Carry item as one node, its one erased run path stamped from Item (FR-009, D-02).

The state of the fresh node reads PENDING, and the stamp is what the loop calls, so Item is checked once here and never again (FR-008).
