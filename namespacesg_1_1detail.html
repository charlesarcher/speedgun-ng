ContextControl& sg::detail::controlOf(const ExecutionContext& context) noexcept
#include <speedgun-ng/execution_context.hpp>

The control block this context owns (FR-001, FR-024).

The class grants this function access to its member, which is the only path from a context to its control block: no side table and no scan stand between the two, and no bound caps the live contexts (FR-001, FR-024). The harness archive defines it, and no caller reaches it (FR-045).

PlacementResult sg::detail::placementRecordOf(const ExecutionContext& context) noexcept
#include <speedgun-ng/execution_context.hpp>

The placement record the thread of this context kept at its start (FR-005, FR-025).

A threaded run reads the disclosed placement field through this function, because the control block of FR-001 stands out of this header (FR-045). The record carries what the installed placement function returned at the start of that thread, which is the account the disclosure of FR-025 prints for a slot that never landed. source/harness/execution_context.cpp defines it, and no caller of the public surface reaches it (FR-045).

Precondition

none

Postcondition

SPEEDGUN_NG_EXPORT auto sg::detail::dispatchNode(const ExecutionContext& context, WorkNodeBase& node) -> void
#include <speedgun-ng/execution_context.hpp>

The erased body of dispatch: the inbox link-swap of FR-003 and the stop linearization of FR-050 (FR-010, FR-050).

source/harness/execution_context.cpp defines it; the dispatch template is its only caller, and the call allocates nothing (FR-040).

Precondition

node stands in no inbox: its state is PENDING with no prior dispatch, DONE, or STOPPED (FR-009, FR-012)

Postcondition
