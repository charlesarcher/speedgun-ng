sg::hunt::HuntOptions struct
#include <speedgun-ng/hunt.hpp>

The settled values of one hunt run (E-03, D-1, D-3, D-6 to D-9).

Contents

  • Reference
    • Public variables

selection holds the text the option carried, because the plan line and the document repeat it; a @file selection holds the joined address lines, because a document that names a file the reader does not have explains nothing. The CLI refuses a value outside the range its option states before this record exists.

The record is data: it holds exactly one run's settled values, and a default-constructed record is the run --hunt names with no other hunt option (D-1, D-3, D-6 to D-9). top and repeats carry the counts of the settled run, noise the threshold it compared against, selection the text of the run that asked for a hunt (the empty text marks hunt options that never met --hunt), and budget nothing for a run no bound limits or the bound in the unit its own kind names (FR-012).
