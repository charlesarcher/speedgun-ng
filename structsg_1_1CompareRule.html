sg::CompareRule struct
#include <speedgun-ng/benchmark.hpp>

One parsed comparison rule (specs/026 E-01, D-01, D-08).

Contents

  • Reference
    • Public variables

The value the rule parse answers and the comparison consumes. text is the exact text the parse call read, the form the table, the fault lines and the document print (D-08); valueName is the value name as written; aggregate stands empty when the text wrote no @ suffix, and a written suffix on a p<point> or stat: name is a parse fault (spec D-21); relativeThreshold is the fraction the percent spelled, 5% answering 0.05, empty when the text wrote none; absoluteThreshold is the number the abs= marker spelled in the stored unit of the value (spec D-22), empty when the text wrote none; filter is the rule's filter text, empty when the rule wrote none.

At least one of the two thresholds stands in every parsed rule: a rule with neither is a parse fault (FR-022, FR-023).
