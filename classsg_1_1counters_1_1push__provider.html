sg::counters::push_provider class final
#include <speedgun-ng/counters_push.hpp>

The shipped push provider: declared counters are ordinary machine-object entries at push read mode (FR-035).

Contents

  • Reference
    • Base classes
    • Constructors, destructors, conversion operators
    • Public functions

Each declared counter lives on the thread that declared it. The hot path adds through the returned handle (a plain non-atomic increment); sampling reads a plain load, never an atomic RMW (R-008).

push_counter sg::counters::push_provider::add_counter(std::string_view name, std::string_view unit, std::string_view description)

Declares one push counter on the machine object, bound to the calling thread, and yields its hot-path handle.

unit is the unit token mapped through the closed switch at registration.

Precondition

name is non-empty.

Postcondition

Enumeration will report the entry at push read mode, and the returned handle adds to the declared counter.
