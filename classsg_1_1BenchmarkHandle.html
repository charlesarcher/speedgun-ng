sg::BenchmarkHandle class
#include <speedgun-ng/benchmark.hpp>

The registration result: the caller's view of one registry entry (E-02).

BenchmarkHandle& sg::BenchmarkHandle::useRealTime()

Make real time the primary time of this family (FR-005).

The qualification test, the growth rule, and the aggregate time statistics read the real column from this call on. The selection excludes the manual-time selection, so the second of the two calls is the violation, in either order (FR-008, D-04).

Precondition

the handle names a registered entry, the run has not started for this benchmark, and this family selects no manual time (E-02, FR-008)

Postcondition

the entry makes the real column the primary time of that family, and the returned handle is this handle (FR-005)

BenchmarkHandle& sg::BenchmarkHandle::useManualTime()

Make the manual sum the primary time of this family (FR-006).

The benchmark supplies one iteration time per iteration through State::setIterationTime, and the primary time of a run becomes the sum of the accepted values. The qualification test, the growth rule, and the aggregate time statistics read that sum, and the fivefold real-time stop leaves a manual run alone (FR-006, D-05). The selection excludes the real-time selection, so the second of the two calls is the violation, in either order (FR-008, D-04).

Precondition

the handle names a registered entry, the run has not started for this benchmark, and this family selects no real time (E-02, FR-008)

Postcondition

the entry makes the manual sum the primary time of that family, and the returned handle is this handle (FR-006)

BenchmarkHandle& sg::BenchmarkHandle::unit(TimeUnit timeUnit)

Set the unit the report scales the printed time values of this family to (FR-015).

A stored time value stays nanoseconds; the report divides each printed time value of that family by the unit's divisor and prints the unit's label. The call overwrites the unit the registration captured from the process default (FR-015, FR-016, D-12).

Precondition

the handle names a registered entry and the run has not started for this benchmark (E-02)

Postcondition

the entry carries timeUnit as the unit of that family, and the returned handle is this handle (FR-015)

BenchmarkHandle& sg::BenchmarkHandle::setup(std::function<void(State&)> callback)

Attach the setup callback of this family (FR-018).

The callback runs once before each run of every instance of the family, the warm-up, calibration, and measured runs included, in the untimed region, so its work adds nothing to the reported time (FR-018). One callback stands per slot and the last attachment wins it (E-07, R-10). The state the callback receives is a harness-built state carrying the instance arguments and the run's iteration count, and it opens no sampling window: reading range(index), rangeCount() and iterations() is legal there, while begin(), skipWithError and skipWithMessage are SG_REQUIRE precondition violations, and end() stays legal because it is static and touches no state (R-05).

Precondition

the handle names a registered entry and the run has not started for this benchmark (E-02)

Postcondition

the entry's setup slot carries callback, the callback this call attached wins the slot, and the returned handle is this handle (FR-018, R-10)

BenchmarkHandle& sg::BenchmarkHandle::teardown(std::function<void(State&)> callback)

Attach the teardown callback of this family (FR-018).

The callback runs once after each run of every instance of the family, after the timed loop and the fixture tearDown, in the untimed region, and it carries the same restricted state as the setup callback (R-05). One callback stands per slot and the last attachment wins it (E-07, R-10).

Precondition

the handle names a registered entry and the run has not started for this benchmark (E-02)

Postcondition

the entry's teardown slot carries callback, the callback this call attached wins the slot, and the returned handle is this handle (FR-018, R-10)

BenchmarkHandle registerBenchmark(std::function<void(State&)> fn, std::string_view name)

Register a benchmark function under a unique name (FR-001).

A runtime registration reaches the registry from any code that runs before the run starts. A repeated name reports a recoverable error, keeps the first registration, and leaves the rest runnable (FR-002).

Precondition

called before the run starts

Postcondition

BenchmarkHandle registerFixtureBenchmark(std::function<void(State&)> fn, std::string_view name, std::function<std::unique_ptr<Fixture>()> factory)

Register a fixture method: the callable plus the factory of the one fixture object each run builds (FR-015, FR-016, R-09).

The fixture macros of FR-016 call this; the factory yields the derived object through the Fixture base, and the runner builds one object per run with it, runs the pair around the callable, and destroys the object after tearDown (FR-017, R-09).

Precondition

called before the run starts, and both fn and factory name a callable (FR-001)

Postcondition

the registry holds one family record under name whose callable is fn and whose fixture factory is factory, and the returned handle names that entry (FR-003, FR-016)

Invariant

the family record's factory yields one fixture object per run of that family (R-09)
