sg::ReportData struct
#include <speedgun-ng/benchmark.hpp>

The value the harness writes as one JSON report and reads back (specs/023 E-01).

Contents

  • Reference
    • Public variables

results holds one entry per benchmark in run order, the order the console prints them. rowRaw[i][k] carries the chunk columns of row k of results[i], and contextRaw[i][k][j] those of context j of that row, so both answer a threaded run whose every repetition captured its own chunks. Both stand empty when the run retained no chunk values, which is what the raw setting at NONE leaves behind. Each carries one outer entry per entry of results, so a reader indexes by result with no search (specs/023 E-01); loadReport answers that pairing as its postcondition.
