sg::ExecutionContext class
#include <speedgun-ng/execution_context.hpp>

One context: one thread, its event loop, its inbox, and its policy (E-01, FR-001).

Contents

  • Reference
    • Constructors, destructors, conversion operators
    • Public functions
    • Friends

The thread takes work only through this context's inbox, an intrusive multi-producer single-consumer queue whose link lives in the work node and whose enqueue allocates nothing (FR-003). The legal lifecycle is requestStop(), drain(), join() in that order: a node whose dispatch observed the not-stopped state runs during drain(), a node whose dispatch observed the stop request is completed STOPPED by its dispatcher, and no node runs after join() returns (FR-006, FR-050).

sg::ExecutionContext::ExecutionContext()

Start one context under the default policy (FR-001, FR-004).

The default policy is BLOCK with no pin (FR-004, Q-2).

Precondition

the slot of the policy names no cpu, or names a cpu the host has online; the default policy names no cpu, so the bound stands satisfied (FR-005, SC-05)

Postcondition

void sg::ExecutionContext::requestStop()

Stand the stop request this context's work items read (FR-006, FR-050).

A node the inbox already holds still runs during drain(); a node a later dispatch offers is refused and completed STOPPED by that dispatch (FR-006, FR-050). The call returns without waiting.

Precondition

none

Postcondition

the stop request stands, so every StopToken of this context reads true and a later dispatch() refuses its node (FR-006, FR-050)

void sg::ExecutionContext::drain()

Wait until the inbox stands empty and the loop stands idle (FR-006, FR-050).

With no prior requestStop() this is a flush: every accepted node ran, and the loop keeps running, so a later dispatch still runs (FR-006). The emptiness stands at the observation the wait made: a dispatch concurrent with this return can refill the inbox, so no postcondition here can re-read it (FR-050).

Precondition

the calling thread is not the thread of this context's loop (FR-050)

Postcondition

none

void sg::ExecutionContext::join()

End the loop and join the thread of this context (FR-006).

Precondition

Postcondition
