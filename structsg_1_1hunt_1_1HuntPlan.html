sg::hunt::HuntPlan struct
#include <speedgun-ng/hunt.hpp>

The plan one hunt run executes (E-04).

Contents

  • Reference
    • Public variables

passes holds the column indices of each pass as the planner answered them; a pass that is not exclusive holds at most max(L - 2, 0) events of a device that publishes L and at most L leaves counting its anchors (I-3). anchorsPerPass is 2 when both anchors exist, else 0, and normalized is false exactly then: the plan normalized by iterations because a device lacked an anchor.
