enum class sg::hunt::HuntNorm: std::uint8_t
#include <speedgun-ng/hunt.hpp>

The denominator one hunt run normalizes an event count by (E-02, D-6).

The names are printed in lower case by the console and the JSON writer through one internal name table each, indexed by the enumerator (E-02).

Precondition

none

Postcondition

INSTR divides by the instructions count of the same pass, CYCLE by the cycles count of the same pass, ITER by the iteration count of the attempt. No enumerator names SENSITIVITY, DELTA or SCORE: N14b adds those when its method exists (D-3)

enum class sg::hunt::SkippedKind: std::uint8_t
#include <speedgun-ng/hunt.hpp>

The refusal of one event, as one skipped entry carries it (E-06, D-10, FR-021, FR-050).

The five enumerators are the counters::Availability values a skipped entry carries, reached through one named mapping function. GAP names the mid-run window disclosure. A group-open refusal that still fails on the solo retry carries the kind of the catalog state its refusal names, the state the counters discovery probe settled for the entry: EINVAL, EOPNOTSUPP and ENOENT settle NOT_ENCODABLE, every other errno settles PERMISSION_BLOCKED, and a refusal that names no state settles ABSENT (D-18, spec PC-1, T118). The console prints every kind with the spelling report.cpp availabilityName prints.

SPEEDGUN_NG_EXPORT auto sg::hunt::planHunt(const std::vector<CatalogAddress>& events, const std::vector<std::optional<std::size_t>>& sourceLimits, const std::vector<std::pair<std::string, std::string>>& anchors, const HuntOptions& options, std::optional<std::uint64_t> calibrationNsPerPass) -> std::expected< HuntPlan, counters::Error >
#include <speedgun-ng/hunt.hpp>

The plan one hunt run executes, over the discovered events, the per-device limits and the anchors (E-04, FR-011, FR-013).

events comes from EventCatalog::split; sourceLimits holds one entry per device: the programmable-counter count that device publishes, or nothing when it cannot answer, built per device path from Object::programmableCounters(), the one source of the limit (spec PC-2). anchors holds the cpu-cycles and instructions addresses per device. calibrationNsPerPass feeds estimateNs alone. An empty events list is not a refusal: it is the shape of a host whose discovery refused every event, and the call then answers zero columns, empty passes, anchorsPerPass zero and normalized false, so the run prints the plan line, the skipped list and the events=0/N summary and exits 0 (D-12, FR-041). The call adds no pass loop of its own and reads no clock, no counter, no /proc, no sysfs and no CPUID (FR-020, I-7).

Precondition

events holds unique addresses in the order the caller asked for; the source index of every entry stands within sourceLimits; anchors holds one pair per device in sourceLimits order, a pair of empty strings where the device lacks cpu-cycles or instructions; options holds the settled values of one run

Postcondition

columns holds one column per entry of events, each naming the two anchors of its own device (I-1); passes is the planPasses answer for the columns and sourceLimits, so a pass that is not exclusive holds at most max(L - 2, 0) events of a device that publishes L, and at most L leaves counting its anchors (I-3, FR-011); a plan that settles on MULTIPLEX has no planPasses answer, and the planner seats the columns itself: one pass over every column, or one pass per group when a multiplex cap stands, the groups standing consecutive in plan order and each at most the cap wide (033 FR-003, N-04, D-3); method is the settleMethod answer, which is MULTIPLEX exactly when no needed device publishes a limit (FR-011, D-19, spec PC-2); stages holds one stage when options.budget is empty: every column at options.repeats; with a budget stages holds two: stage 1 over every column at one repeat and stage 2 over the leading 3 x top columns at options.repeats (D-2, FR-013), the budget rule dropping stage 2 whole when the two-stage estimate does not fit the budget or when a seconds budget has no calibration figure to price it; a stage's repeats holds the count the sample budget derived, at or below that stage's rule and never below one, and holds the rule itself when no calibration figure prices the stage (033 FR-001, FR-002, N-03, D-12); sample holds the state that derivation leaves, the fields HuntSampleState spells (033 N-03, N-06); muxGroups holds the width of each group of a capped plan, every entry at or below the cap and the entries summing to the column count, and stands empty for a plan that settles on PASSES or that no cap binds (033 FR-003, N-04); estimateNs holds calibrationNsPerPass x passes x repeats, the stage-1 figures on a split plan, or stands empty; normalized is false exactly when anchorsPerPass is zero

an event whose device publishes a limit below 3, which detail::admitsHuntEvent refuses, a norm set to instr or cycle whose anchor of that name stands refused (D-13), and a source index outside sourceLimits are each a recoverable error naming the cause; the caller prints one line naming the value and exits 2 (FR-081)

Invariant

passes covers every column index exactly once, so no column stands in two passes

SPEEDGUN_NG_EXPORT auto sg::hunt::rankEvents(const std::vector<EventSamples>& collected, const HuntOptions& options, std::optional<MetricMethod> method) -> EntryHunt
#include <speedgun-ng/hunt.hpp>

The ranked table of the collected samples: one entry per address, the skipped list beside it (E-06, I-5, I-6).

method is the method the collection of collected settled, and nothing else about the table reads it: the rate, the deviation and the rank of an entry are the same figures whichever method filled the window. The record states that method and every row mark is it, so the rank route and the run route cannot name two methods for one table (AC-2, D-19).

The call is pure: it reads no clock and no counter, and two calls over equal arguments give equal results (I-7, FR-014, D-9).

One layer marks: the collection knows why a column gave no rate.

Precondition

each address stands at most once in collected, and options holds the settled values of one run, so top stands above zero and noise above 0.0 in the range its own option states (hunt_plan.cpp:221); every address with no skipped kind holds at least one sample that is free of a disclosure and yields a rate under the norm options.norm names (instr when it is unset), which needs anchorInstr present above zero for instr, anchorCycle present above zero for cycle and iterations above zero for iter: a denominator absent or at zero answers no rate for that pass, so an address that breaches this empties the rate list the guard at statistics.cpp:23-25 protects, and the invariant at hunt_plan.cpp:250 ends the process over it (AC-10); method is the method the plan that produced collected settled, std::nullopt for samples no plan produced; an address with exactly one such sample is reported and never handed to the summary call, so the deviation assert at statistics.cpp:46-48 stays out of reach (PD-14)

Postcondition

one RankedEvent per address in collected and one SkippedEvent per address that carries a skipped kind; an address stands at most once in each list, and an address that measured and gapped stands in both (I-4, D-10); rate is the median of the per-pass normalized rates and cv is the coefficient of variation, both from the single statisticsOf call over those rates, so cv is one hundred times the cv= column ratio of the same samples (I-6); noisy is the comparison of the unrounded cv against options.noise; at most options.top entries carry a rank, those ranks are 1 to k with no gap, and an entry that is noisy or unrepeated carries none (I-5); method states the method the caller handed and multiplexed stands set for every entry exactly when that method is MULTIPLEX; entries come first in rank order and then in address order

a sample whose anchor read zero for its pass contributes no rate for that pass, and a sample with a disclosure contributes none at all, the way a gap repetition stands out of Statistics::samples today

Invariant

no address repeats in entries, and no address repeats in skipped

SPEEDGUN_NG_EXPORT auto sg::hunt::runHunt(BenchmarkHandle& benchmark, const HuntOptions& options, std::optional<std::uint64_t> calibrationNsPerPass) -> std::expected< EntryHunt, counters::Error >
#include <speedgun-ng/hunt.hpp>

The hunt of one registered entry: plan, collection over the harness pass loop, and ranked result (E-06, D-15, D-23).

Public in this header (D-15); the Runner and Instance types it drives behind its definition in source/harness/hunt.cpp stay harness internals, and the signature names public types alone. The driver that assembles the record keeps EntryHunt::passCount equal to the pass count of the plan that ran, the passes a retry appended included (PD-12, D-18), and this call adds nothing to it.

Precondition

options holds the settled values of one run: top and repeats above zero, noise above 0.0 and selection the text --hunt named; benchmark names a registered entry, and the harness registered its providers so the catalog answers

Postcondition

the plan ran through the existing N6 pass loop, so no second pass loop and no second counter path exists (D-23, hard rule 15); every event that produced no value stands in skipped with its kind and the run finished with exit status 0 (D-18); a pass whose group open refused retried its events one at a time inside the same loop, and retriedPasses counts those passes; a seat that fails for pass 0 keeps the existing failure route with exit 1, because it is the same compile that serves warm-up and calibration (spec PC-9); entries covers every planned column, an event that only stage 1 measured holding a record built from its stage 1 samples
