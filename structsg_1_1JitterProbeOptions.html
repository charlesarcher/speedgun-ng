sg::JitterProbeOptions struct
#include <speedgun-ng/benchmark.hpp>

The one argument of every jitter probe entry point (FR-003, FR-015).

Contents

  • Reference
    • Public variables

cpus carries the probe cpu request: an empty vector names the idle preset, and a non-empty vector names the probe cpus in the order given (FR-016, D-4). thresholdNs carries the gap threshold in ns as std::optional<std::uint64_t>: a field with no value names the default rule, the 200 ns default rising to 10 times the measured loop period when that stands larger, and a value stands as given, an explicit threshold=200 staying exactly 200 ns (FR-007, FR-008, D-2). mode carries the default when the option names no mode value (FR-012, D-1). gapCount carries the per-cpu buffer size in records (FR-009). precheckMs carries the pre-check duration in ms (FR-014, D-13). strict stops the run with status 2 when the time-stamp counter stands unavailable; a non-strict run discloses and continues with status 0 (FR-037, D-10). The entry points that take the options require a thresholdNs value at or above 1 when the field carries one, gapCount inside the kMinGapCount through kMaxGapCount range, and precheckMs at or above 1, and enforce the bounds where they parse and bind (FR-008, FR-009, D-13).
