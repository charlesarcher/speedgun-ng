sg::ScopedPauseTiming class
#include <speedgun-ng/benchmark.hpp>

The scoped form of the pause pair: the region from this object's construction to the end of its scope stands outside the timed window (FR-012).

Contents

  • Reference
    • Constructors, destructors, conversion operators
    • Public functions

The constructor calls State::pauseTiming and the destructor calls State::resumeTiming, so the interval the guard bounds is the interval the explicit pair bounds. The preconditions and postconditions of those two calls stand once on the calls themselves (FR-011). The destructor skips the resume when the run was skipped, so a guard that leaves its scope on a skip path cannot turn one breach into a second (FR-012).

Close the pause interval, and leave it open when the run was skipped (FR-012).

The destructor calls resumeTiming, and its contract guards run under this class's implicit noexcept. The trap semantics of the default contract build ends the process on a violation, the message naming the broken pause pair. In a build whose handler throws, a violation surfacing from this destructor ends the process while it unwinds.
