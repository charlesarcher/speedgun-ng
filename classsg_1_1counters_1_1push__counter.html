sg::counters::push_counter class
#include <speedgun-ng/counters_measurement.hpp>

Hot-path handle of a push counter: a plain, non-atomic uint64 increment on the creating thread, sampled by plain load (FR-035, R-008).

Contents

  • Reference
    • Constructors, destructors, conversion operators
    • Public functions

Declared through push_provider before registration. Cross-thread add is a tier-3 violation, checked by default and elided under SG_CONTRACTS_IGNORE.
