sg::CompareEntry struct
#include <speedgun-ng/benchmark.hpp>

One benchmark under one comparison rule (specs/026 E-02, FR-002, FR-044, FR-054).

Contents

  • Reference

The table row and the document entry. name is the full instance name; ruleText is the text of the rule that produced the entry; baseline and contender are the two values in the stored unit, empty for ADDED, REMOVED and SKIPPED; changePercent is the signed change as a percent of the baseline magnitude, empty when that magnitude is zero or no value stands; changeAbsolute is the signed change in the stored unit, empty when no value stands, and positive when the contender is worse for the rule's direction, so the word and the sign agree; reason stands empty except on NOISY, where it names the bound, the carried warning or the running ratio that fired (FR-044).
