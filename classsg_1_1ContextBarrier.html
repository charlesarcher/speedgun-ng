sg::ContextBarrier class
#include <speedgun-ng/execution_context.hpp>

The round a fixed set of participants meets on (E-04, FR-014, FR-015).

Contents

  • Reference
    • Constructors, destructors, conversion operators
    • Public functions

Every round stands until all participants arrive, then releases them at once (FR-014). A waiting participant waits in the wait mode of its own policy, or in BLOCK when it runs on no context; the barrier reads no clock, so no round times out (FR-014, Q-3). The call is legal from inside running work and outside it (FR-015). A threaded run meets on two of these, one round outside the start of every window and one outside the end of every window (FR-019, D-05).

Invariant

the arrival count of a round never exceeds the participant count fixed at construction (FR-014)

void sg::ContextBarrier::arriveAndWait()

Arrive at this round and wait until it releases (FR-014, FR-015).

The wait reads no clock and takes no timeout (FR-014). A caller that leaves before this round releases, or that stands in another round of this barrier at the same time, splits the round; no code of this class can see either, so the duty stands outside the contract (FR-015).

Precondition

none

Postcondition

the generation of this barrier stands past the round this call arrived at, so every participant of that round has arrived (FR-014)
