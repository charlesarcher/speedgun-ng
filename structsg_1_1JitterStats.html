sg::JitterStats struct
#include <speedgun-ng/benchmark.hpp>

The C++ value the harness exposes for one benchmark; the console report formats it and adds nothing to it (FR-036, E-07).

Contents

  • Reference

The suite and case pair splits the instance name the way contracts/result-fields.md derives it, and a later JSON report of the roadmap reuses the pair (FR-021, R-07). ResultRow carries neither field: it is one repetition or aggregate (FR-021).

The jitter result of one probe cpu over one set of covered windows: the sixteen fields of data-model.md E-03 in the E-03 order (FR-002, R-05).

The percentile fields follow the nearest-rank rule of source/harness/percentiles.cpp over the sorted kept gaps (PC-4), the rule the report columns fill through. The fold of an empty kept set leaves every field at 0. The fold functions of the probe carry the field relations this struct's fills establish; the aggregate itself imposes nothing at construction.
