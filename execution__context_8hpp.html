speedgun-ng/execution_context.hpp file

The execution context surface: a context that owns one event-loop thread, the policy of its wait and its placement, the typed work node a caller dispatches to it, and the barrier its work items meet on.

Feature 020-execution-contexts-core. Namespace sg. Every name here is the name contracts/execution-context.md states, and the four H16 hooks (the node completion state, dispatch() from inside running work, ContextId, the placement slot) carry the meaning H16 reads on top of them (FR-045). source/harness/execution_context.cpp defines what this header declares, inside the speedgun-ng_harness archive and behind no new target (FR-043).

The counts and the ordinals of this surface (a thread count, a context count, a thread index, a context index, a barrier participant count) take plain int, the spelling the shipped counters::Target::cpu already carries (FR-001). PlacementSlot::cpu keeps std::uint32_t, because that index feeds the counters System matching (FR-005).
