sg::TopdownRecord struct
#include <speedgun-ng/benchmark.hpp>

The top-down record one benchmark carries: the source of its nodes, the nodes, and the rows the table refused (specs/042-topdown data-model.md E-16, FR-032, FR-033, spec D-14).

Contents

  • Reference
    • Public variables

supported says whether the selection answered a tree, and reason carries the one line it answered when it answered none. reference and directory are the manifest reference and the selected directory of the table the rows came from. files holds one entry per file that contributed a row, with E-02's name and digest, in the sorted order the embedder emits. askedLevel is the level the option asked for and level the level the record shows, so the clamp to the table's own depth stays visible (FR-015, FR-020). nodes holds the collected nodes and refused the rows that table refused at or above that level.

No vendor flag rides the record. The fifth level-1 name and the 100 percent statement are printed on the block, and the document carries no key for either (FR-011, FR-028).

The struct is data: it holds no call to guard. The shape no member may break is the pair the option states: an absent record carries no node, and a record that states no support carries empty files, nodes and refused beside its reason.
