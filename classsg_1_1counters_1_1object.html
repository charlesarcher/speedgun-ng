sg::counters::object class
#include <speedgun-ng/counters_system.hpp>

One countable object in the system tree (E-02).

Handles are stable pointers into the tree; the tree is immutable after the system opens, so they stay valid (FR-009). Every result spells the canonical path; alias strings never appear in output (FR-002).

template<class D>
std::expected<sg::counters::counter<D>, error> sg::counters::object::counter(std::string_view name) const

Resolves one named counter under the requested dimension (FR-005, FR-008).

The catalog unit of the named counter must map to D; a mismatch is a recoverable error naming both, a unit token outside the closed mapping is a recoverable error naming the unit, and a wrong name is a recoverable error carrying near-miss suggestions (at most five, names within edit distance two first, then description word overlaps, catalog order breaking ties). Nothing is guessed (FR-017).
