# F-3 again, on the acceptance host, the day the lane was written

F-3 rests on one claim: a single read of the leader's enabled and running pair
settles whether a group size fits, with no sleep, no spin and no clock read
between the enable and that read. This artifact is that measurement re-run on
the acceptance host with the tool this lane ships at `tools/probe_window.c`, so
the claim names a program and a table rather than a memory.

Two shapes are read. Table F enables the group, spins a fixed number of
iterations, disables, then reads. Table G reads once while the group is still
enabled, which is the shape the shipped probe takes. Column `fit` counts the
trials whose pair read `time_running == time_enabled` with `time_enabled` past
zero; `no_fit` counts the trials that read short. Every cell is 50 trials.

    cc -O2 -o probe_window tools/probe_window.c && ./probe_window

perf_event_paranoid=2,
nmi_watchdog=0,
device `cpu` type 4.
Date: 2026-11-05.
